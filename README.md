# Hospital Management System

This project is a **Hospital Management System** developed using **Spring Boot**.  
It is created as a **learning project** to understand backend development, REST APIs, and database integration.

## Purpose of the Project
- Learn Spring Boot framework
- Build RESTful APIs
- Understand backend architecture
- Practice CRUD operations
- Work with database integration

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- MySQL / H2 (can be configured)

## Features
- Patient management
- Doctor and staff management
- CRUD operations
- REST API based architecture
- Layered structure (Controller, Service, Repository)

## Project Structure
- Controller layer – handles HTTP requests
- Service layer – contains business logic
- Repository layer – database operations
- Entity layer – database models

## How to Run the Project
1. Clone the repository
2. Open the project in an IDE (IntelliJ / Eclipse / STS)
3. Configure database in `application.properties`
4. Run the application as a Spring Boot app
5. Access APIs using Postman or browser

## Note
This project is developed for **learning and academic purposes** and may not include all real-world hospital features.
